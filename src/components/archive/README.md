# Legacy / Reference Components Archive

These components were developed during early UX iterations of Mezon Sprint OS:
- `WeeklySpreadView.tsx`: Analog 2-page moleskine spread prototype. Superseded by Alan Cooper transient views (`MorningFocusView`, `EveningDebriefView`, `SaturdaySelfStudyView`, `WeeklyRetroView`).
- `MentorClassDrawer.tsx`: Drawer prototype. Superseded by `MentorDashboardView.tsx`.
- `PlannerTopBar.tsx`: Earlier top bar. Superseded by `NavigationHeader.tsx`.

Preserved here for design lineage and reference.
